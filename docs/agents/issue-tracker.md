# Issue tracker — GitHub Issues

Issues live at: https://github.com/Ezoxima/sorare-mlb/issues

## CLI

```bash
gh issue create --title "..." --body "..."
gh issue list
gh issue view <number>
gh issue edit <number> --add-label "..."
```

## Conventions

- One issue per bug or feature
- Link in commits with `Closes #<number>` when resolved
